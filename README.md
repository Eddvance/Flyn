# Flyn

A social platform built with a microservices architecture.

The project includes a React Native mobile application and a set of Java / Spring Boot services designed to handle the different parts of the platform.

## Architecture

- Cerberus — Authentication and security
- Columba — Messaging and real-time communication
- PacificShare — Activities, notifications and social features
- Winyx — Data compression service

### Frontend

React Native

### Backend

Java 21 • Spring Boot • Spring Security • PostgreSQL • RabbitMQ

### Infrastructure

Eureka Service Discovery
